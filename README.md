# 👨‍💻 Programmers Guide

**Programmers Guide** is a beginner-friendly website designed to help people who want to start learning programming but don't know where to begin.

The project aims to reduce confusion by providing a clear path:

**Learn Fundamentals → Explore the Market → Choose a Field → Follow a Roadmap**

## 🚀 Features

* 📚 **Programming Fundamentals** — Introduction to the basics and recommended learning resources.
* 💼 **Job Market** — Useful resources to explore technologies and programming jobs in the market.
* 🗺️ **Roadmaps** — Learning paths for Web Development, Mobile Development, AI & Data Science, and Cybersecurity.
* 💡 **Programming Tips** — Practical advice to help beginners learn effectively and avoid common mistakes.

## 🛠️ Technologies

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactivity and dynamic behavior
* **Git & GitHub** — Version control
* **GitHub Pages** — Deployment
